## ⚡ Quick Summary: What Makes This Different?

Most resume builders are built for generalist jobs, relying on decorative 2-column templates, skill rating bars (e.g., "80% Python"), and graphic elements that fail Applicant Tracking Systems (ATS) and irritate technical hiring managers.

**CV Builder takes the opposite approach:**
- 📄 **100% Single-Column Layout:** Zero text boxes, zero multi-column parsing traps.
- 🎯 **Inspired by Academic $\LaTeX$ Standards:** Clean, high-density, scannable layout modeled after Jake's Resume and Deedy styles.
- 📏 **Strict 1-Page Constraint:** Real-time visual page limit indicator with density presets (`Compact`, `Normal`, `Spacious`).
- 🤖 **Built-in Quality & ATS Audit:** Live linter checking punctuation, action verbs, and quantifiable metrics.
- 💾 **Offline & Private:** Saves directly to `localStorage` with full JSON import/export capability. Zero tracking, zero server lock-in.
